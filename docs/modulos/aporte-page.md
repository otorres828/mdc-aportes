# AportePage

Base abstracta sin ruta ni vista propia. Fija el layout y reúne mensajes de error, restauración de propiedades concretas del borrador y consulta de un comprobante por propietario. No almacena todos los campos ni decide qué pantalla se muestra. Las clases concretas conservan mount seguido de render y, para Save*, save inmediatamente después.
